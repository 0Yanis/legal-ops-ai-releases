## Εγκατάσταση

1. Κατεβάστε το `.exe` ή το `.zip`
2. Εκτελέστε τον installer / `Setup.bat` με δικαιώματα διαχειριστή
3. Το app ξεκινά αυτόματα και ανοίγει στο browser (localhost)

## Ενημέρωση

- Μέσα στο app: Ρυθμίσεις → Δίκτυο → Ενημερώσεις
- Ή εκτελέστε `Apply-Patch.ps1` από το Launcher bundle
